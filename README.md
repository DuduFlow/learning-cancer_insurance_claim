# 癌症，其實比你想的更近

> 癌症理賠案例課程 — 學習筆記網頁

一頁式的課程筆記網站，把兩小時的口述課程整理成業務同仁能快速吸收、隨時翻查的形式。

## 內容

| 章節 | 內容 |
|---|---|
| 01 數據 | 罹癌比例變化、攝護腺癌成長率、遺傳佔比等課堂引用數據 |
| 02 費用 | 18 項自費治療的真實金額清冊 + **「你有多少子彈」互動試算** |
| 03 案例 | 16 個真實理賠案例卡片，可依「理賠爭議／費用真相／錯過的警訊／額度＝選擇權」篩選 |
| 04 爭議 | 五種理賠爭議類型與條款重點 |
| 05 自檢 | 三個自我檢查部位 + 六個身體警訊 |
| 06 金句 | 12 句可直接帶去見客戶的話 |
| 07 行動 | 八項具體業務動作（三講、報價落差、實支組合、核保放寬名單等） |

## 檔案結構

```
.
├── index.html          # 頁面結構
├── assets/
│   ├── style.css       # 樣式
│   ├── app.js          # 互動與渲染
│   └── data.js         # 所有課程內容資料（要改內容改這裡）
├── .nojekyll           # GitHub Pages 用
└── README.md
```

## 修改內容

所有文字都在 `assets/data.js`，不需要動 HTML。各個陣列對應：

- `HERO_STATS` — 首頁三個大數字
- `FACTS` / `TREAT_COUNT` — 01 數據
- `COSTS` — 02 費用清冊（同時是試算器的資料來源，`total` 單位為萬元）
- `CASES` — 03 案例（`tag` 可填 `claim` / `cost` / `early` / `choice`）
- `DISPUTES` — 04 理賠爭議
- `CHECKS` / `WARNINGS` — 05 自檢
- `QUOTES` — 06 金句
- `ACTIONS` — 07 業務行動

### 公開發佈前請注意

`assets/data.js` 第一行有一個開關：

```js
const ANONYMIZE_COMPANIES = false;
```

改成 `true` 之後，「04 理賠爭議」段落的保險公司名稱會自動改以 **A～E 公司** 代號顯示，其餘內容不變。若這個 repo 是 public，建議打開。

## 發佈到 GitHub Pages

1. 建立 repo，把整個資料夾內容推上去
2. Settings → Pages → Source 選 `Deploy from a branch` → `main` / `/ (root)`
3. 等一兩分鐘，網址會是 `https://<帳號>.github.io/<repo 名稱>/`

純靜態、無相依套件，直接用瀏覽器開 `index.html` 也可以看。
